## 这是什么

视觉交付物质量规则：质量优先总纲、对称与平衡、数据类交付默认可视化（图优先于表）、 AI 生图默认自动调用（仅本地 ComfyUI，无云端兜底；真人保脸走 MiniMax 面板）； 视频画面素材走本地 MiniMax H3 生成，不许用 HTML/SVG 简图充数（2026-11-12 用户拍板）。 文字类交付正文默认微软雅黑，可换字体但需说明理由。 当制作任何面向观看的产出（HTML/报表/PPT/海报/视频/设计稿/网页）、需要配图、 AI 生图、改图、换发型换装时，使用此 skill。 triggers: - 海报 - PPT - 视觉交付 - 配图 - AI 生图 - 生图 - 改图 - 设计稿 - 网页设计 - 做页面 - 好看的 - 视频制作 allowed-tools: - Bash - Read
